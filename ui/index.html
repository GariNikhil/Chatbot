Quick start

  • Double-click start.bat — starts LM Studio + this server and opens the UI (if using LM Studio).
  • Settings ▸ End session stops the server from the UI. stop.bat does the same from the file manager.
  • Manual: Start your LLM provider (LM Studio or Ollama), configure LLM_PROVIDER in .env, then cd server && npm start, open http://localhost:3001.

Chatting with agents

  • Pick an Agent, optionally a Scene — only scene participants stay selectable (toggle them in the Scene panel). A scene linked to a Scenario also receives that story's persistent foundation.
  • Turn on Group chat in the Agents panel to talk to every AI participant of the current scene at once. Each scene has one shared room and timeline; characters can reply to you and to each other.
  • Toggle World Cards via Settings ▸ World Cards to change tone/setting for new messages.
  • Pick a model in the composer dropdown; a red banner means LM Studio is offline.
  • Use the ☰ button in the header to hide/show the sidebar. The choice is remembered; on a phone the sidebar opens as a drawer.

Tags

  • Character, scenario, scene, and world-card forms include searchable tag pickers backed by house/tags.yaml.
  • Scenario tags describe the overall story; scene tags describe the current chapter. They are saved separately and injected at the correct level.
  • Selected tags are saved as stable ids (tag_selections) alongside your written descriptions; clearing a tag never edits the text fields.
  • Tags relevant to each entity are added to the model's system prompt. Deleted or non-applicable tags are preserved in the YAML and shown as removable Unavailable chips.

LLM Provider

  • LM Studio (default, port 1234): lms server start, lms load qwen3-4b, lms server status
  • Ollama (port 11434): ollama serve, ollama pull qwen3:4b, ollama list
  • Set LLM_PROVIDER=ollama in .env to use Ollama. Configure with OLLAMA_BASE_URL or LLM_BASE_URL.

Scenarios & scenes

  • A Scenario is the whole story: premise, relationships, genre, and world facts that persist across chapters.
  • A Scene is one chapter: its own location, situation, and the characters present right now.
  • Create a scenario in Settings ▸ Scenarios, then link scenes to it there (tick Include all scenes or pick individual chapters) or per scene in Settings ▸ Scenes. Scenes without a scenario remain standalone.
  • The Scene selector groups chapters under their scenario. While chatting, the chapter bar above the messages lets you jump between the chapters of the current story (for example Living Room → Kitchen). Switching chapters changes the immediate context but keeps the story foundation, characters, and world cards.
  • Exchanges for memory-enabled characters are saved as Markdown under Chatbot/Memories/scenarios/<story>/<scene>/<character>/ (or standalone/ for scenes without a story) in your Obsidian vault, and replayed only in the same scene. Older Memories/<character>/ files are still shown and read.
